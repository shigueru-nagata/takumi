# Trademark Policy for Takumi

This policy outlines the rules for the name and logos associated with the **Takumi** project.

## 1. Ownership
The name **Takumi** and all official logos, artwork, and icons are the exclusive intellectual property and trademarks of the project creator. 

## 2. Permitted Use
You are welcome to use the name **Takumi** and its logos to:
* Refer to the original, unmodified source code hosted in this repository.
* Create a fork on GitHub for the purpose of contributing via Pull Requests.

## 3. Independent Projects & Redistribution Guidelines
The GNU GPLv3 license allows you to modify and distribute the source code. However, if you decide to fork this project to create a **separate, permanently independent derivative product** (a hard fork) or redistribute modified binaries outside of this official repository:
* **Change the Brand:** You **must change the name** of the application and **remove the official logos** so users can clearly distinguish your independent project from the original **Takumi**.
* **No False Affiliation:** You may not use the name **Takumi** in a manner that implies official endorsement, sponsorship, or a formal relationship with the original project.
